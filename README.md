# 業務報告シート (マンション清掃管理)

スマホから簡単に業務報告を作成し、画像化してLINEで送信できるWebアプリケーションです。
専用のサーバー環境は不要で、GitHub Pagesなどの静的ホスティングを利用してすぐに無料で運用を開始することができます。

## 🎯 目的と特徴

*   **完全無料&サーバー不要**: HTML, CSS, JavaScriptのみで動作します。
*   **スマホ最適化**: タップしやすいボタン、見やすい文字サイズなど、スマホでの利用に特化しています。
*   **スムーズなLINE共有**:
    1.  報告書を画像として生成・保存
    2.  そのまま「LINEを開いて送る」ボタンからLINEアプリを起動
    3.  オーナーへの画像送信という既存の運用フローを崩しません。
*   **オフライン下書き機能**: 入力途中のデータはブラウザのローカルストレージに自動保存（下書き）されるため、誤ってブラウザを閉じても安心です。
*   **履歴機能**: 過去の報告履歴を最大保存容量まで保持・確認できます。

## 🚀 使い方 (エンドユーザー向け)

1.  スマホのブラウザ（SafariやChromeなど）から、公開されたURLにアクセスします。
2.  ホーム画面に追加（ウェブクリップ）しておくと、アプリのように全画面で起動でき便利です。
3.  フォームに沿って、「基本情報」「毎回の業務」「マンスリー業務」「報告事項」を入力します。
    *   日付は自動で今日の日付が入ります。
    *   時刻は「現在」ボタンですぐに入力できます。
4.  一番下の **「📄 報告書を作成」** ボタンを押します。
5.  プレビュー画面が表示されます。
    *   【1. 画像をスマホに保存】ボタンを押して、画像をダウンロードします。
    *   【2. LINEを開いて送る】ボタンを押してLINEアプリを起動し、オーナー宛に先ほど保存した画像を送信します。

## 🛠 導入方法 (GitHub Pagesでの公開)

このリポジトリをGitHub Pagesで公開する手順です。

1.  GitHub にログインし、新しいリポジトリを作成します。
2.  このリポジトリに `index.html` およびこの `README.md` をアップロード（またはプッシュ）します。
3.  リポジトリの **Settings** (設定) を開きます。
4.  左側のメニューから **Pages** を選択します。
5.  **Build and deployment** の Source を `Deploy from a branch` に設定します。
6.  Branch を `main` (または `master`) に設定し、フォルダは `/ (root)` を選んで **Save** ボタンを押します。
7.  数分待つと、画面上部に公開されたWebサイトのURLが表示されます（例: `https://[あなたのユーザー名].github.io/[リポジトリ名]/`）。
8.  そのURLをお母様のスマホにLINE等で送り、ブラウザで開いてもらえば準備完了です。

## 🔧 カスタマイズ

業務内容を変更したい場合は、`index.html` の下部にある以下のJavaScriptの配列を書き直してください。

*   `regularTaskDefs`: 毎回の業務リスト
*   `monthlyTaskDefs`: マンスリー業務リスト

```javascript
// 例：新しい項目を追加
const regularTaskDefs = [
  ...
  { id: 'r12', label: '新しい清掃箇所', detail: '水洗い' },
];
```
